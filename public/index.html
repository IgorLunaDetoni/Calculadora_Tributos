CONECTE A FONTE DOS DADOS

Integrações oficiais

Conecte as instâncias das calculadoras RTC para usar o motor da Receita Federal.

Como conectar

  1. Instale os projetos oficiais e gere o banco de dados conforme os respectivos READMEs.
  2. Execute as APIs do regime regular e do Simples Nacional.
  3. Configure RTC_REGULAR_URL e RTC_SIMPLES_URL no servidor, se usar endereços diferentes dos padrões.
  4. Verifique a conexão e selecione “API RTC” na operação.

O navegador acessa as APIs pelo servidor local deste projeto. Credenciais de serviços externos não são armazenadas no cadastro da empresa.
